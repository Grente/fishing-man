# 鱼类美术提示词（fish-pro）

用于生成图鉴 / 捕获弹窗用的 2D 鱼立绘。统一约束如下，再拼接每种鱼的专属描述。

## 通用前缀

```
Cute stylized 2D fish illustration for a mobile fishing game,
side view, clean vector-like shapes, soft cel shading,
transparent background, centered composition,
no text, no watermark, high contrast silhouette readable at 128px
```

## 通用后缀

```
bright tropical colors, friendly expression, large eye,
simple fins, game UI icon quality, PNG style
```
