# 潮汐系统

实现：`scripts/autoload/tide.gd`（Autoload `Tide`）。

## 行为

周期循环：低潮 → 平潮 → 高潮 → 平潮 → …

| id | 显示名 | 持续(秒) | 咬钩倍率 | 稀有倍率 | 市场偏差 |
|----|--------|----------|----------|----------|----------|
| low | 低潮 | 180 | 1.3（更慢） | 0.7 | -0.04 |
| mid | 平潮 | 240 | 1.0 | 1.0 | 0.0 |
| high | 高潮 | 180 | 0.7（更快） | 1.4 | +0.05 |

- `bite_mul`：影响等待/咬钩节奏
- `rare_mul`：影响稀有/传说鱼权重
- `bias`：传入市场，影响今日行情倾向

## UI

**HUD 不再显示潮汐标签**；潮汐仅作为后台系统影响玩法与行情。

仍可通过 `Tide.get_tide_display()` / `tide_changed` 信号读取状态（供调试或未来 UI）。
