# 地图与世界布局

## 尺寸

| 项 | 值 | 来源 |
|----|----|------|
| 视口 | 720 × 1280（竖版） | `project.godot` |
| 世界 | **2880 × 2560** | `WorldConfig.SIZE` |
| 岸线 Y | **2050** | `WorldConfig.SHORE_Y` |
| 码头 X | **1100** | `WorldConfig.DOCK_X` |
| 停靠点 | **(1145, 1760)** | `WorldConfig.DOCK_BERTH` |

- Y 轴：北（远海，小 Y）→ 南（陆地，大 Y）
- 水域：`y < SHORE_Y`；陆地：`y >= SHORE_Y`
- 渔船仅在水上移动；鱼群不生成在陆地

## 区域分带（概略）

| 区域 | 大致 Y 范围 | 鱼种 |
|------|---------------|------|
| 远海 | 北侧水域 | 红鲷 / 石斑 / 鲹王 |
| 中海 | 中部水域 | 金枪鱼 / 旗鱼 / 鬼头刀 |
| 近海 | 靠近岸线 | 沙丁鱼、鲹鱼、海鲲、小丑鱼、河豚、蝴蝶鱼 |

具体鱼点由 `ocean_world.gd` 程序化生成，浮标分近/mid/远海三色。

## 码头与建筑

码头（木栏）位于画面中偏左（`DOCK_X = 1100`）。

三座建筑在**码头右侧**（间距约 360），自左向右：

1. **工具店** — `building_toolshop.png` → 买船 / 买竿
2. **海鲜市场** — `building_market.png` → 行情列表
3. **图鉴** — `building_encyclopedia.png` → 鱼类图鉴

停靠点 `DOCK_BERTH` 在码头尖端北侧水面（略偏右），**不在木板上**。

## 风景

- 陆地：棕榈、灌木、防晒伞等（`_place_decor` 避开建筑矩形）
- 无游客 NPC（已移除）

## 摄像机与 HUD

- 摄像机跟随渔船，限制在世界边界内
- 左上：资源面板（金币 / 货舱 / 油），青绿玻璃底 `Color(0.102, 0.165, 0.196, 0.92)`
- 右上：迷你地图（同色底）
- **不再显示潮汐 HUD 标签**（潮汐仍在后台运行）
