# 试玩操作

目标平台：触控（编辑器可用鼠标模拟）。

## 船行

| 操作 | 效果 |
|------|------|
| 点击水面 | 渔船驶向该点（消耗油） |
| 点击陆地 | 无效（船不上岸） |
| 靠近停靠点 | 进入码头待命，显示码头菜单 |

## 钓鱼

| 操作 | 效果 |
|------|------|
| 靠近鱼群/浮标 | 显示「抛竿」 |
| 点「抛竿」 | 等待咬钩，出现时机条 |
| 时机区内点击 | 上钩，进入张力拉锯 |
| 拉锯：按住 | 收线，张力↑，进度推进 |
| 拉锯：松开 | 泄力，张力↓ |
| 张力过载 / 过松 | 断线或脱钩，本杆失败 |

## 码头建筑

| 点击 | 效果 |
|------|------|
| 工具店 | 买船 / 买竿 / 装备 |
| 海鲜市场 | 全部 12 种鱼行情（可上下滑动） |
| 图鉴 | 网格 + 单鱼详情 |

## 码头菜单（HUD）

- 卖出货舱
- 升级船 / 升级竿（等级型）

## Toast

居中提示：如「金币不足」、货舱满、油不足等。
