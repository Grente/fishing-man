# 美术风格

## 总体

- 2D 俯视海岛 / 渔港风情
- 色调：清澈蓝绿海水 + 暖码头木色 + 明亮码头建筑
- 触控友好：大按钮、清晰中文标签

## 配色（UI）

| 用途 | 颜色 |
|------|------|
| 资源面板 / 迷你地图底 | `Color(0.102, 0.165, 0.196, 0.92)` 青绿玻璃 |
| 主按钮 | `btn_list_primary*.png` 胶囊 |
| 次按钮 | `btn_list_secondary*.png` |
| Toast | 屏幕居中半透明条 |

## 鱼类立绘

- 2D 插画，侧面或 3/4 侧，透明底
- 已发现：彩色；未发现：灰度
- 生图提示词：`prompt/fish-pro.md`
- 成品：`assets/fish/*.png`

## 捕获反馈

- 大尺寸鱼图 + 旋转 `catch_sunburst.png`
- NEW 徽章、居中描述与重量/估价

## 渔船视觉
