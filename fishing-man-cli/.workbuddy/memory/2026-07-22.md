- `project.godot`：预览窗口 `window_width/height_override` 由 405×720 改为 720×1280（= 设计分辨率，缩放 1.0，WYSIWYG）。原 0.5625 缩放是"字太小"的主因。
- `scripts/ui/ui_theme.gd`：主题默认字号 18→22（Label 18→22，Button 20→24）。
- `scripts/ui/game_ui.gd`：金币 24→30、货舱 18→22、油/潮 16→20、Toast 20→24、抛竿按钮 28→34、继续按钮 22→26、码头按钮 20→26、小地图标题 16→22、提示 16→22；TopLeft 高度 210→240；**码头弹窗改为锚点居中**（`set_anchors_preset(PRESET_CENTER)`，±250/±240）。
- `scripts/ui/market_panel.gd`：列表鱼名 18→22、区域 13→18、稀有度 15→20、价格 18→22、涨跌 15→20。
- `scripts/ui/encyclopedia_panel.gd`：图鉴卡名 18→22、状态 14→18。
- `scenes/main.tscn`：**捕获弹窗 CatchPanel 改为锚点居中**（anchors_preset=8，±280/±380，原来竖向偏上 40px）；各内联字号上调（HUD/码头标题/等待/钓鱼提示/捕获名/NEW/价格/描述/市场标题/图鉴标题/图鉴提示/详情鱼名）。

### 经验（重要）
- Godot 编辑器会实时回写 `.tscn`，Edit 时频繁出现 "modified since read" / EBUSY。改场景文件后必须重新读取核对落盘，失败的重做。`.gd` 文件受影响较小但同样偶有锁竞争。
- 弹窗居中应优先用锚点（PRESET_CENTER / anchors_preset=8 + 对称 offset），而非硬编码 offset，否则换分辨率就歪。
